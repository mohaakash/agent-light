# AgentLight v0.2.0-beta.1

## Highlights

- Optional animated Taby face widgets with Classic, Calm, and Expressive face sets; classic traffic lights remain the default.
- Directional hotzone reveal/retreat animation that slides from the selected screen edge (no fade/clip wipe), with normalized monitor/DPI-aware presets including top- and bottom-center positions and adaptive notch corners for Taby faces.
- Audio and desktop notifications for attention transitions, completion tones, Do Not Disturb, timed snoozes, and tray controls.
- Click-to-focus for agent sessions, enriched hook context, and project-folder fallback.
- Native Rust hook integration management with install/uninstall, backups and restore, status diagnostics, bridge verification, and test signals.
- Faster development startup by creating widget windows on demand and deferring integration diagnostics and serial-port scans until their tabs are opened.

## Validation

- `npm run build`
- `npm run lint`
- `npm run test:assets`
- `npm run test:integrations`
- `cd src-tauri && cargo fmt --check && cargo test`

The animated-face artwork is from the Taby firmware asset pack. Attribution and its artwork terms are included in the repository and bundled asset directory. Manual visual verification of the notch/face presentation and hotzone transition on a running desktop build remains recommended.
